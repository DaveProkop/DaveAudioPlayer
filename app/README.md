# DaveAudioPlayer – Flutter app

UI for the Rust core in `../rust`. The bridge is generated by
[flutter_rust_bridge](https://github.com/fzyzcjy/flutter_rust_bridge) 2.13 from
`../rust/crates/api/src/api/`, and `rust_builder/` (cargokit) compiles that crate as part
of every `flutter build` / `flutter run`.

## Requirements

- Flutter (stable), Rust (stable, MSVC on Windows)
- Windows: Visual Studio C++ workload, **Developer Mode** enabled (plugins use symlinks)
- Android: SDK + NDK, Rust targets `aarch64-linux-android armv7-linux-androideabi x86_64-linux-android`

## Common commands

```sh
flutter run -d windows                      # run the app
flutter build apk --debug                   # Android build
flutter test                                # Dart unit tests
flutter test integration_test -d windows    # Rust core through the bridge, end to end
flutter test integration_test/ui_screens_test.dart -d windows  # PNG of every screen (DAP_SHOTS)
flutter_rust_bridge_codegen generate        # after changing rust/crates/api/src/api/*
```

The library database lives in `%APPDATA%\DaveAudioPlayer\library.db` on Windows and in the
app's files directory on Android.
